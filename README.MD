## Возможности плагина

* команда «Send Code» отправляет выделенный фрагмент кода в Telegram
* вызов из контекстного меню редактора, горячей клавишей и через палитру команд
* перед отправкой у кода убирается общий отступ слева, а переносы строк Windows (`\r\n`) приводятся к `\n`
* сообщение оформляется так: имя файла, затем код в блоке ` ``` ` с указанием языка, поэтому Telegram показывает его моноширинным шрифтом
* Telegram Desktop открывается с окном выбора чата, и сообщение уже стоит в поле ввода
* если файл не открыт или ничего не выделено, выводится сообщение об ошибке

## Архитектура

Используем базовый шаблон для создания плагина в VS code, сам плагин пишем на JS. В `package.json` мы объявляем наше расширение TelegramExtenson, называем команды (`SendCode`). В файле `extension.js` ввесь код расширения. Мы пишем несколько функций:

1. `dedent` - убирает лишний общий отступ, возвращает очищеннную строку
2. `SendCode` - функция отправки кода, через `vscode.window.activeTextEditor` получаем выделенный текст в редакторе, форматируем текст, готовим сообщение (получаем название языка программирования, а также нормальную разметку), а затем с помощью `vscode.env.openExternal` мы открываем Telegram для отправки текста.
3. `activate` - функция активации расширения
4. `deactivate` - функция деактивации

**Докумнтация плагина** - папка telegram-extension, файл API.MD
